## dsh-ima v1.11.1

把腾讯 ima 知识库接进 DeepSeek Harness。这一版是**功能补齐 + 界面重做**：从"只能读"变成"能读也能写"，并修掉了几个会让人一眼看出是半成品的问题。

### 最重要的三件事

**1. 能写入了**
之前只能读。不是 ima 没开放——是我方调用 `create_media` 时少传了 `content_type` 和 `file_ext` 两个必填字段，服务端报的 `invalid media_type` 极具误导性，找了两天才定位。

现在：点「上传」选文件、或直接把文件拖进面板，就能传上 ima。支持 23 种格式，重名自动保护（ima 不支持覆盖，选「保留两者」会自动加时间戳）。

**2. 文件图标全部重做**
查证发现 DSH 客户端对附件只画一个通用纸夹，没有「按格式区分」的图标体系。硬套界面动作图标，就出现 txt 显示成播放键这种错乱。

现在自绘 17 种格式图标：折角纸 + 格式特征（表格格子 / 投影屏幕 / 音符 / 播放键 / 地球 / 尖括号…），形状优先、颜色辅助。

还修了一个更隐蔽的问题：**ima 返回的类型标签不能直接用**——它按「内容来源」归类，从录音转写来的 `.txt` 会被标成「录音」。现在以文件名为准。

**3. 界面不再是瞬变**
数据来自远程接口（300ms~3s），之前除了一个转圈没有任何反馈。现在：

| 场景 | 反馈 |
|---|---|
| 首次加载 | 6 行骨架屏 shimmer，与真实行同高，加载完不跳动 |
| 刷新列表 | 顶部 2px 进度条 + 旧列表降到 45%（不闪白） |
| 进入文件夹 | 列表逐项淡入上移，级联 18ms |
| 打开预览 | 淡入 220ms |
| 拖文件进面板 | 遮罩渐显 180ms |
| 多文件上传 | 每行独立状态 + 呼吸竖条 + 流动进度条 |
| 出错 | 带图标的 Alert，附「重试」 |

### 其他改动

- **面板内搜索**：`Ctrl K` 跨全部知识库搜正文，结果按知识库分组，点一条直接打开并高亮命中处、自动滚过去
- **授权状态**：右上角一个盾牌图标（绿点正常 / 黄点超过 7 天没验证），点开看详情
- **排序**：名称 / 类型两档。ima 不返回时间字段，所以**不做**「按最近更新」——不造假数据
- **Agent 工具**：从 5 个增加到 7 个（新增 `ima_upload_file`、`ima_add_url`）
- **无障碍**：焦点环、键盘 Tab + 回车、触控目标 ≥32px、支持 `prefers-reduced-motion`

### 修的 Bug

- **React error #310**（"界面出了点问题"红框）：`useEffect` 写在条件 return 之后，未绑定→绑定成功时 Hook 数量变化。已修，并加了静态检查脚本防复发
- **27 个主题变量全部校正**：原先引用的 `--dsw-alias-interactive-bg-primary`、`--dsw-alias-status-danger`、`--dsw-alias-bg-secondary` 等在 DSH 里**根本不存在**，等于全靠硬编码兜底，深色主题下会出现白字白底。从 DSH 的 CSS 导出全部 98 个真实变量逐一核对
- 上传按钮图标从回形针改为 `+`（回形针让人误解）
- 适配 DSH 0.2.2-rc.1：`webServer.register()` 补 `kind` 字段，否则路由根本注册不上

### 安装

```bash
dsh plugin --profile web add https://github.com/ikevss/dsh-ima/releases/latest/download/dsh-ima.tgz
```

桌面端把 `web` 换成 `desktop`。装完重启 DSH。

### 已知边界

| 项 | 说明 |
|---|---|
| 订阅知识库 | ima 产品策略不开放读取，默认不显示 |
| 文件更新时间 | ima OpenAPI 不返回任何时间字段，插件预留了显示通道 |
| 上传上限 | 约 30MB |
| 视频链接 | Bilibili / YouTube 等只能在 ima 桌面端内添加，接口不支持 |
| 笔记段落结构 | ima 只返回一段展平的纯文本，原始段落边界在服务端就丢了，插件按锚点尽力还原，右上角「看原文」可对照 |
